Desenvolvimento de um Painel Gerencial para Negócio com o Streamlit.

Nesse projeto, os conceitos de Programação em Python, manipulação de dados, pensamento estratégico e lógica de negócio, junto com ferramentas de desenvolvimetno web como o Streamlit e Github, foram usados para desenvolver um painel gerencial com as principais métricas de uma empresa de serviço online de busca de restaurantes, fundada na India.

Ensaio de Machine Learning.

Neste projeto, trabalhei na prática com diferentes algoritmos de Machine Learning aplicados a problemas de classificação, regressão e agrupamento. O foco foi entender como a alteração dos principais hiperparâmetros influencia o comportamento dos modelos, especialmente na relação entre underfitting e overfitting.

Ao longo dos testes, comparei diferentes configurações e analisei como cada ajuste impactava a performance dos algoritmos. Como resultado, desenvolvi um painel interativo que permite visualizar e comparar o desempenho dos modelos conforme os parâmetros são modificados, facilitando a compreensão do processo de ajuste e seleção de modelos.

Ferramentas Utilizadas

  • Python e Scikit-learn
  • Algoritmos de classificação: KNN, Decision Tree, Random Forest e Logistic Regression
  • Algoritmos de regressão: Linear Regression, Decision Tree Regressor, Random Forest Regressor, Polinomial Regression, Linear Regression Lasso, Linear Regression Ridge, Linear Regression Elastic Net, Polinomial Regression Lasso, Polinomial Regression Ridge e Polinomial Regression Elastic Net
  • Métricas de performance: Accuracy, Precision, Recall e F1-Score
  • Métricas de performance: R2, MSE, RMSE, MAE e MAPE
  • Algoritmos de agrupamento: K-Means e Affinity Propagation
  • Métricas de performance: Silhouette Score
